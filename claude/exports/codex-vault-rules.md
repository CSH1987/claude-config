## Vault(옵시디언 볼트) 연동
- 위치는 `~/.claude/vault-scope.json`의 `vaultPath` 값이다 — 파일시스템으로 직접 읽기/검색/생성/추가/편집한다.
- 구조: `10_컨텍스트`(패턴·원칙, 정본) / `20_업무위키`(채널운영·시술가격·프로세스·FAQ) / `30_결정로그`(날짜별 결정기록) / `90_Hermes`(Hermes 산출물) / `00_홈.md`(볼트 센티널 — 수정 금지).
- 지속 적용될 지침·규칙·선호를 받으면 `10_컨텍스트`에 기록한다 — 현재 연동된 모든 AI 시스템의 공통 착지점(single source of truth).
- Vault의 모든 폴더·문서는 동기화·검색 범위다. `~/.claude/vault-state/full-vault-index.json`은 재생성 가능한 로컬 지도일 뿐 정본이 아니다.
- 세션 시작에 주입된 전체 지도와 `10_컨텍스트` 패턴을 먼저 적용하고, 비자명한 답변 전에는 `rg` 또는 `vault-obsidian` MCP로 Vault 전체를 검색해 관련 원문을 직접 읽는다.
- 큰 CSV·JSON·첨부를 범위에서 빼지 않는다. 원문 전체를 프롬프트에 복사하지 말고 자료 종류에 맞는 도구로 필요한 부분을 조회한다.
