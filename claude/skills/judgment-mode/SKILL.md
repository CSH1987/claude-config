# 판단력 모드

이 스킬이 불려나왔다는 건 지금 이 턴이 판단력 중심 순간이라는 뜻이다(frontmatter의 `model: opus`로 이번 턴 나머지는 자동으로 상위 모델 — 적응형 플랜의 `ANTHROPIC_DEFAULT_OPUS_MODEL` 재매핑을 그대로 탄다).

이 스킬은 `advisor()`를 **대체하지 않고 보완**한다 — 서로 다른 두 층이다:
- 이 스킬(모델 자체를 상위로): 지금 내가 더 깊게 생각한다.
- `advisor()`(독립 재검토): 다른 관점에서 내 판단을 검증받는다.

## 지침

1. 결정을 내리기 전에 트레이드오프를 명시적으로 나열해라 — 대안을 최소 1개 이상 비교하지 않고 바로 결론으로 가지 마라.
2. 되돌리기 어렵거나 비용이 큰 판단이면 결론 전에 `advisor()`를 호출해라(CLAUDE.md "모델 전략" 절의 표준 습관).
3. 확신(근거 있음)과 추론(전제→논리→결론)을 사용자에게 구분해서 보여줘라 — 뭉뚱그리지 마라.
4. 이 스킬을 사소한 질문에 남발하지 마라 — 매 턴 자동으로 상위 모델로 전환되는 게 아니라, 진짜 판단력이 걸린 순간에만(빈도가 늘면 비용도 는다).
